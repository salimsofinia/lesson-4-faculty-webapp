# Share A Lesson – Messaging App Project

This project is a web-based messaging-style application where users can **share brief lessons**, **categorize them by faculty**, and **vote** on them using emojis. It mimics a lightweight forum aimed at enhancing peer learning on campus.

---

## Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Custom styling with responsive layout
- **JavaScript (Vanilla)** – DOM manipulation and interactivity
- **Supabase** – Used as the backend (database + authentication if applicable)

---

## Features

- Post short "lessons" with a title and source
- Select from predefined faculty categories
- Emoji-based voting system: 👍, 🤯, ⛔
- Dynamic filtering by faculty
- Fully responsive layout for desktop and mobile
